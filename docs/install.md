# 설치 안내

[← README로 돌아가기](../README.md)

## 요구 사항

- Apple 실리콘 Mac (M1 이상). Intel Mac은 지원하지 않습니다.
- macOS 13 이상. 개발과 시험은 macOS 26에서 했습니다.

## 설치하기

1. [Releases](https://github.com/eddieee-git/Floaty/releases)에서 `Floaty.dmg`를 내려받습니다.
2. dmg를 열고 Floaty를 Applications 폴더로 끌어다 놓습니다.
3. dmg를 꺼냅니다.
4. Applications 폴더에서 Floaty를 실행합니다.

실행해도 Dock에는 아이콘이 생기지 않습니다. 화면 위쪽 메뉴바에 압정 꽂힌 메모지 아이콘이 나타나면 정상입니다.

## 처음 실행할 때 나오는 보안 경고

인터넷에서 받은 Floaty를 처음 열면 macOS가 실행을 막고 경고 창을 띄웁니다. 문구는 macOS 버전에 따라 조금씩 다르며, 대개 Apple이 악성 코드 여부를 확인할 수 없다는 내용입니다.

**왜 나오나요?** macOS는 Apple의 유료 개발자 프로그램으로 서명하고 공증받지 않은 앱을 기본으로 막습니다. Floaty는 무료 프로젝트라 이 인증을 받지 않았습니다. 앱에 문제가 발견되어 나오는 경고는 아닙니다. 다만 Apple이 검사하지 않았다는 뜻은 맞습니다. 믿을 수 있는 곳에서 받은 파일만 여세요. 코드는 이 저장소에 공개되어 있어서 직접 확인하고 [빌드](../README.md#직접-빌드하기)할 수도 있습니다.

### 방법 1: 시스템 설정에서 허용

1. 경고 창에서 **완료**(버전에 따라 **확인**)를 눌러 닫습니다. **휴지통으로 이동**은 누르지 마세요.
2. **시스템 설정 → 개인정보 보호 및 보안**을 엽니다.
3. 아래로 내려 **보안** 항목의 Floaty 안내 옆에 있는 **그래도 열기**를 누릅니다.
4. 확인 창이 나오면 다시 **그래도 열기**를 누르고, Mac 암호나 Touch ID로 승인합니다.

처음 한 번만 하면 됩니다. 새 버전을 설치하면 다시 해야 할 수 있습니다.

### 방법 2: 터미널 명령

터미널을 쓴다면 이 명령 하나로 대신할 수 있습니다. Floaty를 Applications 폴더로 옮긴 뒤에 실행하세요.

```bash
xattr -dr com.apple.quarantine /Applications/Floaty.app
```

"손상되었기 때문에 열 수 없습니다"라는 문구가 나올 때도 이 명령으로 풀 수 있습니다.

## 잠금을 풀 때 나오는 인증

스티커 잠금을 풀 때는 Touch ID나 Mac 로그인 암호를 묻습니다. macOS가 직접 처리하며, Floaty는 지문이나 암호를 받지도 저장하지도 않습니다.

## 로그인할 때 자동으로 실행하기

메뉴바 아이콘 → **설정…** → **모든 스티커** 탭에서 **로그인 시 자동 실행**을 켭니다. Floaty를 Applications 폴더에 둔 뒤에 켜세요.

## 업데이트

1. 메뉴바 아이콘 → **Floaty 종료**로 앱을 끕니다.
2. 새 `Floaty.dmg`를 열고 Applications 폴더로 끌어다 놓아 기존 앱을 대체합니다.

스티커와 설정은 앱과 따로 저장되므로 그대로 남습니다.

## 다른 Mac으로 옮기기

Floaty를 끈 뒤 아래 폴더를 복사해서, 다른 Mac의 같은 위치에 넣습니다.

```text
~/Library/Application Support/Floaty
```

이 폴더에는 스티커만 들어 있습니다. 단축키와 색 같은 설정은 다른 Mac에서 다시 정해야 합니다.

## 삭제

1. 메뉴바 아이콘 → **Floaty 종료**로 앱을 끕니다.
2. Applications 폴더에서 Floaty를 휴지통으로 옮깁니다.

스티커까지 지우려면 아래 명령을 실행합니다. **모든 스티커가 영구히 지워지니** 먼저 필요한 내용을 저장해 두세요.

```bash
rm -rf ~/Library/Application\ Support/Floaty
```

설정도 지우려면 아래 명령을 실행합니다.

```bash
defaults delete com.eddieee.Floaty
```
